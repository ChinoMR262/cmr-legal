1. Alcance

Esta política explica cómo CMR Writer Lite trata la información en su versión actual. La aplicación permite organizar historias, capítulos, personajes, lugares, objetos y cronologías de forma local.

2. Información que se guarda

  • Proyectos, capítulos, personajes, lugares, objetos, cronologías y formato de texto creados por el usuario.
  • Preferencias locales, como el idioma elegido.
  • Backups .cmr cuando el usuario decide crearlos, importarlos, guardarlos o compartirlos.

Esta información se procesa y guarda en el dispositivo o en la ubicación que el usuario elija. CMR no recibe por defecto el contenido narrativo.

3. Información que no recopilamos

La aplicación no requiere cuenta, no ofrece sincronización en la nube, no incorpora anuncios ni utiliza analítica propia o seguimiento publicitario. No solicitamos ubicación, contactos, SMS, llamadas, cámara ni micrófono.

4. Archivos y aplicaciones externas

Al compartir un backup, el archivo se entrega a la aplicación o persona que el usuario seleccione. Esa entidad puede tratarlo según sus propias políticas. CMR no controla copias exportadas fuera del dispositivo.

5. Finalidad

La información se usa para ofrecer escritura, organización, preferencias, backup, importación, exportación y recuperación local. No vendemos ni alquilamos el contenido del usuario.

6. Conservación y eliminación

El usuario puede eliminar proyectos desde la aplicación y backups desde la ubicación donde los guardó. Desinstalar la aplicación elimina los datos locales según el comportamiento de Android, pero no elimina archivos exportados o compartidos con terceros.

7. Seguridad

Los datos locales quedan protegidos por el dispositivo y el sistema operativo. Los backups .cmr no son una bóveda cifrada; deben guardarse y compartirse con cuidado.

8. Cambios y consultas

Si una función futura cambia la forma de tratar información, actualizaremos esta política indicando una nueva fecha. Para consultas sobre privacidad, escribí a chinooficial262@gmail.com.
